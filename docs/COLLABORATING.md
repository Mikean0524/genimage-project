# Collaborating

Clone the repository, install the dependencies for the stage you are working on from the relevant `requirements-*.txt` file, and follow `RUN_PIPELINE.md`.

The repository contains code, documentation, and sample provenance. The 2.32 GB image sample, generated outputs, and model weights stay outside Git. See `data/genimage_sample/README.md` for the sample source and reconstruction notes. Do not commit local secrets or credentials.

Create a branch for each change, push it, and open a pull request for review. Share access through the repository host's collaborator or team settings.
